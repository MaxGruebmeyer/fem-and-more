# FEM and more

This repo contains (or will contain) the code I wrote while trying to learn FEM.
I would like to become the kind of person who can look at any difficult math,
physics or engineering problem and immediately know how to attack it. Since most
problems are to difficult to solve by hand, this naturally requires a computer.
And this is where classical Numerical Analysis, and more precisely, Numerics of
PDEs and the Finite Element Method (FEM) enters the picture.

Since I had some Numerics background but did not want to take another course I
thought: Why not learn it by myself? Why not do a bunch of fun projects to learn
the basics and go from there?
Even two years ago this would have been very difficult, since Numerics is really
hard (even for me, who has a lot of programming experience). But luckily for
me (in this case) we live in the age of clankers, which incidentally are pretty
good at generating exercises. As good as someone who has spend their live mastering
these topics? Probably not. Good enough to create a mini-curriculum for me?
You bet.

Since FEM might be one of my largest gaps but sure as hell not the only one I
split this project into two parts:
-   Part A): Basics of FEM, with some optional appendix projects
-   Part B): Some extensions bridging more modern methods like inverse problems,
    rNLA, model reduction, data-driven approaches and more

Again, the goal is to become a well-rounded computational scientist/applied
mathematician. There is also a second goal, which is becoming more and more
important the better AI gets: Fun. I really like this topic, I like learning
new things, I like solving problems, and I feel like this project will bring me
a lot of joy :)
